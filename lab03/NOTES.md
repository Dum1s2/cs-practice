git diff
Показывает изменения между рабочей папкой и индексом.

git show
Показывает содержимое конкретного коммита:изменения,автора,дату,сообщение.

git log
Показывает историю коммитов:изменения,сообщения,автора,даты.

git log -S
Ищет коммиты,в которых изменилось количество вхождений указанной строки.

git blame
Показывает,какой коммит и какой автор изменил каждую строку файла.

git restore восстанавливает файл из текущего состояния HEAD.
Мои незакоммиченные изменения в этом файле были бы отменены,файл вернулся бы к состоянию последнего коммита.

git restore --source= позволяет восстановить файл из указанного коммита.
В этом случае файл получил бы содержимое из выбранного коммита,мои текущие незакоммиченные правки также были бы заменены этим содержимым.

git revert не удаляет существующий коммит из истории.
Он создаёт новый коммит, который отменяет изменения указанного коммита.

git reset --hard перемещает указатель текущей ветки на другой коммит и
приводит рабочие файлы к состоянию этого коммита. При этом изменения после
указанного коммита могут быть удалены из рабочего репозитория.

Для уже опубликованной истории безопаснее использовать git revert, потому
что он не переписывает историю и не меняет существующие коммиты.

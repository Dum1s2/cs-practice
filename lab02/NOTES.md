рабочая папка - файлы которые я реактирую
индекс - область в которую добавляются файлы после git add перед коммитом
коммит - фиксация индекса в истории, в нем сохраняется информация об авторе
Git - система контроля версий локально
GitHub - сервис для хранения репозиториев и совместной работы
git diff показывают изменения до git add а git diff --staged после,перед коммитом
Использованные команды:
git status - показывает состояние: измененные файлы,состояние индекса,на какой я ветке
git diff - сравнивает рабочую папку с индексом
git diff --staged - сравнивает индекс с коммитом
Ветки:
ветка - указатель на коммит,который позволяет вести парралельную работу не касаясь основной ветки. при новом коммите указатель ветки сдвигается на новый коммит не трогая остальные ветки
слияние веток - объединение изменений из одной ветки в другой и соединяет истории обеих веток
